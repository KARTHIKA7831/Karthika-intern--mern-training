Day 4 — Mongoose Model & Database CRUD
What I learned

Learned what Mongoose is and how it works with MongoDB.

Learned the difference between a schema and a model.

Learned how a Mongoose model is used to perform database operations.

Learned that data stored in MongoDB remains available after restarting the server.

What I built

Created a Mongoose schema for notes.

Added title, body, and createdAt fields.

Created the Note Mongoose model.

Replaced in-memory data operations with MongoDB operations.

Used Note.find() to retrieve notes.

Used Note.create() to create notes.

Used Note.findByIdAndUpdate() to update notes.

Used Note.findByIdAndDelete() to delete notes.

Added handling for notes that are not found.

Testing

Tested all four CRUD operations with MongoDB.

Confirmed that notes are stored in the database.

Restarted the server and verified that existing notes were still available.
